== Description ==

LearnSchool is a clean, playful, and accessible Full-Site Editing (FSE) block theme designed for schools, early learning centers, academies, and educational institutions. Built with modern WordPress `theme.json` v3 standards, fluid typography, self-hosted fonts, global style variations, and modular educational block patterns.

== Features ==

* Full Site Editing (FSE) support with custom block templates and template parts
* 27 modular Block Patterns for heroes, academics, admissions, faculty, events, FAQs, and footers
* 3 Global Style Variations (Coral Playground, Pastel Nursery, Sunshine Playful) plus custom block styles
* Fluid Typography & Responsive Spacing Tokens
* Privacy-first: self-hosted WOFF2 fonts with zero external CDN requests

== Installation ==

1. In your admin panel, navigate to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
4. Open Appearance > Editor to customize templates, styles, and block patterns.

== Frequently Asked Questions ==

= Does LearnSchool require any third-party plugins? =
No. LearnSchool is a native Full Site Editing block theme built entirely with core WordPress blocks. You can optionally install any contact form or newsletter plugin of your choice and place its block in the provided CTA or footer columns.

= Can I customize the colors and typography? =
Yes. You can switch palettes or adjust colors, typography, and spacing directly through Appearance > Editor > Styles (Global Styles).

== Privacy ==

LearnSchool does not collect, store, or transmit personal visitor data, set tracking cookies, or make external font or third-party CDN requests. All fonts and visual assets are bundled locally within the theme package.
