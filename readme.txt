== Description ==

LearnSchool is a clean, modern, and accessible Full-Site Editing (FSE) block theme designed for schools, academies, universities, and educational institutions. Built with WordPress modern block theme standards, fluid typography, WCAG 2.2 AA compliant contrast, and modular educational block patterns.

== Features ==

* Full Site Editing (FSE) support
* Native Block Patterns for Academics, Admissions, Campus, News, and Events
* Fluid Typography & Responsive Spacing Tokens
* WCAG 2.2 AA Accessible Color Palette
* 100% Native Block Markup (Zero bloated runtime JavaScript)
* Privacy-first: No external CDN fonts or tracker scripts (GDPR compliant)

== Installation ==

1. Upload the theme folder to `/wp-content/themes/learnschool/`.
2. Activate LearnSchool via Appearance > Themes in your WordPress admin.
3. Open Appearance > Editor to customize your site with the Site Editor.

== Frequently Asked Questions ==

= Does LearnSchool require any third-party plugins? =
No. LearnSchool is a native Full Site Editing block theme that functions entirely on core WordPress blocks.

= Can I customize the colors and fonts? =
Yes. You can customize the color palette and typography directly through Appearance > Editor > Styles (Global Styles).
